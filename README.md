# Tips (v0.2)
SCP: Classified Site plugin

С определённым промежутком времени выводит спектаторам админмесседж с любым текстом, который указан в конфиге.

Конфиг:
- **tips** - сообщения, которые будут выводиться спектаторам. Можно выводить разные сообщения. Для этого используйте разделительный знак **|**. Пример: ```tips: <size=20><color=red>Сообщение №1</color></size>|<size=20><color=blue>Сообщение №2</color></size>```;
- **delta_tips_time** - как часто будут выводяться сообщения (по умолчанию: 60);
- **tips_time** - как долго будут висеть сообщения (по умолчанию: 10).
